# eNSP GUI 界面布局参考

本文档描述 eNSP V1.3.00.100 主界面的典型布局，用于辅助坐标定位。

## 主窗口布局（默认 1920x1080 屏幕）

```
┌──────────────────────────────────────────────────────┐
│ 标题栏：eNSP - [拓扑名]                    [最小][最大][关闭] │
├──────────────────────────────────────────────────────┤
│ 菜单栏： 文件(F) 编辑(E) 视图(V) 工具(T) 设备(D) 帮助(H) │
├──────────────────────────────────────────────────────┤
│ 工具栏： [新建] [打开] [保存] | [启动] [停止] | [撤销] [重做] │
├────────────┬─────────────────────────────────────────┤
│            │                                         │
│  设备树    │          拓扑编辑区（画布）              │
│  (左侧面板) │                                         │
│            │                                         │
│  - 路由器  │                                         │
│  - 交换机  │                                         │
│  - 终端    │                                         │
│  - 安全    │                                         │
│            │                                         │
├────────────┴─────────────────────────────────────────┤
│ 状态栏：就绪 | 设备数：X | 已启动：Y                     │
└──────────────────────────────────────────────────────┘
```

## 关键区域相对坐标（0-1000 基准）

| 区域 | 大致坐标范围 | 说明 |
|------|-------------|------|
| 菜单栏 | y ≈ 50 | 顶部菜单条 |
| 工具栏 | y ≈ 90 | 快捷按钮区 |
| 左侧设备树 | x: 0-150, y: 120-900 | 设备类型面板 |
| 拓扑画布 | x: 150-1000, y: 120-920 | 主编辑区 |
| 状态栏 | y ≈ 950 | 底部状态信息 |

## 常用菜单位置

- **文件菜单**：x ≈ 30, y ≈ 50
- **设备菜单**：x ≈ 350, y ≈ 50
- **全部启动**：设备菜单下第 X 项
- **全部停止**：设备菜单下第 X+1 项

## 设备状态图标含义

- **灰色**：设备未启动
- **绿色闪烁**：设备启动中
- **绿色常亮**：设备运行正常
- **红色**：设备启动失败或异常

## CLI 窗口特征

- 双击设备后弹出的独立终端窗口
- 标题栏显示设备名称，如 `AR1`
- 黑色背景，白色/绿色文字
- 提示符通常为 `<Huawei>` 或 `[Huawei]`
